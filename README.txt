# The Wallet Studio — Static Website

## Files
- index.html
- style.css
- script.js
- assets/logo.jpg
- assets/products/design-01.jpg ... design-14.jpg

## Run
Open `index.html` in a browser, or use Replit/GitHub Pages.

## Add a new design
1. Put the image in `assets/products/`, for example `design-15.jpg`.
2. Add one object to the `products` array in `script.js`.
3. The gallery will render it automatically.

## Instagram
The ordering buttons copy a design-specific message to the clipboard, then open:
https://ig.me/m/the.walletstudio

This avoids relying on unsupported Instagram pre-filled DM URL behavior.
